# iMessage Connector

Your coding agent texts you on iMessage — and answers your conversations, in your name or its own, under rules it cannot loosen.

**Site:** https://connected-mate.github.io/imessage-connector/ · [Français](https://connected-mate.github.io/imessage-connector/fr/)

## Install

Copy this prompt into your coding agent (Claude Code, Codex, Cursor, Gemini CLI, Copilot, Windsurf…). It installs everything and asks you before anything sensitive:

> Install iMessage Connector on this Mac and set up my conversations. Follow https://github.com/Connected-Mate/imessage-connector/blob/main/AGENT-SETUP.md exactly, and ask me, for each conversation, whether you answer as me or as yourself. Ask me before anything sensitive and before sending any message.

Optional menu bar app (signed and notarized): [download](https://github.com/Connected-Mate/imessage-connector/releases/latest/download/iMessage-Connector-macOS.dmg).
